# T01 Legacy Plus prompt 계약

Legacy Plus는 새 장문 narrative prompt를 만들지 않는다. 기존 Legacy `buildPrompt()`가 본문 흐름을 계속 소유한다.

추가되는 최소 지시는 다음이다.

- 제공된 학원 정보와 학원별 review만 사용한다.
- 실제 소재지를 정확히 쓴다. 주변 후보를 대상 지역 소재로 쓰지 않는다.
- 가격·셔틀·합격률·후기·체험담을 추측하지 않는다.
- 적격 review가 있는 후보 학원은 학원당 정확히 1건만, 연결 학원 직후에 인용한다.
- review 원문이 100자 이상이면 제공된 100자 이내 말줄임표 버전을 그대로 사용한다.
- review의 실제 source label을 정확히 표시한다.
- 체크리스트는 행동이고 FAQ는 그와 다른 추가 설명일 때만 쓴다.
- 거리 수치·km·이동시간·교통 편의 단정을 쓰지 않는다.

사진은 기존 T01과 동일하게 후보 학원당 제공된 원천 사진 슬롯 1장만 해당 학원 카드에 배치한다.

다음 내부 표현은 prompt나 본문에 넣지 않는다: typed candidate, retrieval source, stored-region-like, supplement/far, region relation, missing fields, quality rule ID.

비교표의 공통 필드는 typed context에서 계산하지만 내부 구조는 노출하지 않는다. 값이 대부분 비어 있는 열은 제외하도록 지시한다.

## 2026-07-21: 소재지 중심 구도 완화

Legacy Plus에만 `readerFlow` opt-in 지시를 추가했다. 기존 Legacy, v2, Hybrid의 prompt는 변경하지 않는다.

- 글의 순서는 `독자 질문 → 학원별 차이 → 객관 정보 → 선택 도움`을 따른다.
- 면허 과정·운영 형태·자체시험 여부·학원별 실제 review를 후보 비교의 우선 재료로 둔다.
- 실제 소재지는 오표현 방지용 사실이다. 실제 지역이 다른 학원도 `지역 내`·`인근` 후보군으로 나누지 않고 같은 비교 단위로 소개하며, 비교표 또는 해당 학원 소개에 실제 지역명만 짧게 쓴다.
- 전체 주소와 전화번호는 비교표의 기본 열이나 후보 소개의 첫 문장으로 사용하지 않는다.
- `가까운`·`근처` modifier는 Legacy Plus prompt에서만 독자용 수식어로 전달하지 않는다. 후보 선정과 provenance 보존에는 영향을 주지 않는다.
- 페르소나에 출발지·통학·출퇴근 같은 이동 제약이 명시된 경우에는 생활권·동선을 독자가 확인할 조건으로 제한해 사용할 수 있다. 주소만으로 특정 학원의 통학 편의·접근성·셔틀 가능성을 판단하지 않는다.

새 prompt 계약과 Legacy 기본 prompt의 격리는 `apps/api-nest/test/t01-legacy-plus.test.ts`의 reader-flow 회귀 테스트로 확인했다. 실제 재생성 평가는 아직 수행하지 않았다.

## 2026-07-21: 비교 재료와 Legacy 서술 흐름

Legacy Plus는 원천 `seo_description`에서 명시적으로 확인되는 면허 과정만 정규화해 prompt 초반으로 옮긴다. 원문 SEO 설명·SEO 키워드는 생활권·동선 별칭을 본문으로 흘려보내지 않도록 그대로 전달하지 않는다.

비교 재료는 다음 순서로 찾되, 어느 하나를 도입과 모든 학원 소개의 고정 주제로 강제하지 않는다.

1. 모든 후보에 과정 정보가 있으면 `면허 과정`을 표 또는 실제 차이가 있는 학원 설명에 활용한다.
2. 그렇지 않고 학원 유형이 실제로 다르면 `운영 형태`를 보조 비교 재료로 활용한다.
3. 둘 다 부족하면 후보 설명을 억지로 늘리지 않고 `짧은 객관 정보와 공통 확인 순서`로 축소한다.

도입은 지역에서 면허를 준비하는 독자의 현실적인 고민으로 열고, 후보별 소개는 한두 문장의 자연스러운 서술 뒤에 기본 정보 불릿으로 이어진다. 과정·운영 형태·리뷰는 실제 차이가 있거나 선택에 도움이 될 때만 쓴다. 세 경우 모두 주소·전화는 기본 정보로 유지한다. `BEST` 제목 규칙은 SEO 용도로 유지하며, prompt는 순위·최상급의 사실 근거를 만들지 않는다.
