# T01 Legacy Plus 사람 블라인드 평가 안내

평가 자료는 `data/content-generation-evaluation/t01-legacy-plus-blind-20260721-0940/blind/`에 있다.

- `review-pairs.md`: 네 표본 링크
- `sample-01.md` ~ `sample-04.md`: X/Y 익명 원문과 평가표
- `review-pairs.csv`: 오프라인 평가 입력
- `reviewer-guide.md`: 평가 원칙
- `review-source-appendix.md`: review 충실도 확인용 최소 source 정보

평가자에게 mode, native/neutral issue, selector/dedupe 결과, 자동 metric, private mapping을 제공하지 않는다. 각 글은 지역 검색 의도, 흐름, 후보 설명, 소재지 정확성, 비교, review, checklist/FAQ, 가독성, 광고성, AI 느낌, 게시 가능성을 1~5점으로 평가한다.

Pair별 선택은 `X가 확실히 더 좋음 / X가 약간 더 좋음 / 비슷함 / Y가 약간 더 좋음 / Y가 확실히 더 좋음 / 둘 다 사용하기 어려움` 중 하나다. 오류 의심 문장은 후보명과 함께 기록한다.
