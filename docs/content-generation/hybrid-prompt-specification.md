# T01 Hybrid Prompt Specification

완성 prompt 문자열이 아니라 구현 가능한 block 명세다. internal JSON key, retrieval rank, missing field 목록, 거리 수치를 독자 문장에 노출하지 않는다.

## 1. 역할과 사실 원칙

- 한국어 지역 운전면허학원 비교 글을 쓰되, 제공 candidate만 소개한다.
- 주소/운영 과정/가격/셔틀/시간/합격률/review는 제공 facts가 있을 때만 사실로 쓴다.
- 지역 밖 후보는 실제 소재지와 “주변 후보로 함께 비교한 이유”를 정확히 쓰되, 거리 숫자·km·이동시간을 쓰지 않는다.
- 결측 facts는 독자의 결정에 중요한 항목만 짧은 상담 질문으로 전환한다.

## 2. 글 흐름

1. 지역 독자의 선택 상황과 비교 범위.
2. 선택 기준; 확장 후보가 있으면 포함 이유를 한 번 설명.
3. 후보 카드: 확인된 사실 → 의미 → 적합 이용자 → 필요한 확인 1개.
4. 선택된 실제 수강생 review 0..1개; 학원 연결, 짧은 원문/충실 요약, `출처: label`.
5. coverage가 충분한 공통 fields만 쓴 비교표 또는 결정 가이드.
6. 짧은 행동 checklist.
7. checklist/body와 topic이 겹치지 않는 FAQ 0..N개.
8. 지역/과정/상담 조건을 종합하는 결론. CTA는 review를 반복하지 않는다.

## 3. 후보·review block

후보 카드는 같은 문장 골격을 복제하지 않는다. review block은 다음 제약을 가진다.

```md
> “선택된 실제 리뷰 원문 또는 충실한 짧은 요약” — 출처: {source.label}
```

작성자·날짜·평점·review ID·동기화 시각은 출력 금지다. source가 없거나 selection이 없으면 block 자체를 만들지 않는다.

## 4. 문체와 output

존댓말, 친근하지만 정보 중심, 2~3문장 문단, 자연스러운 전환을 기본으로 한다. 질문/감탄/최상급은 제한한다. “확인 필요”를 후보마다 반복하지 않고, 비교 결정에 중요한 항목에서만 사용한다. 현재 renderer가 요구하는 Markdown H1/H2/H3·표·이미지 slot 계약은 유지한다.
