# 운전선생 스타일 심층리서치 범위

외부 콘텐츠의 고유 제목·문장·후기·CTA를 복제하지 않는다. 이 리서치는 hybrid facts/provenance/gate 설계가 확정된 뒤 **독립 style/composition profile**을 정하기 위한 것이다.

## 현재 자료만으로 결정 가능

- legacy 기반 자연스러운 narrative scaffold 유지
- T01 v2 typed facts, provenance, data-gated variant, factual gate 유지
- 실제 review 전체 1개, source 표기, metadata 미표시
- 거리 숫자 본문 미노출 및 지역 관계 반복 억제
- FAQ/checklist semantic dedupe
- prompt에는 핵심 원칙, 상세 검수는 gate

## 리서치가 필요한 변수

| 변수 | 측정 단위 |
| --- | --- |
| 질문 빈도/어미 | 1,000자당 질문 수, 종결어미 분포 |
| 문장·문단 리듬 | 문장 길이, 문단당 문장 수 |
| 소제목/후보 전환 | 패턴 다양성, 정보 label 비율 |
| review 배치 | 후보 직후/표 뒤의 이해도와 광고성 |
| 비교표·결론 | 표의 위치, CTA 설득 강도 |
| 독자 호칭 | 직접 호칭 빈도와 부담감 |

시점: hybrid data/gate 설계를 먼저 구현·A/B/C로 검증한 후 profile로 추가한다. 스타일 리서치를 먼저 하면 현재의 review/FAQ contract 문제와 문체 문제를 혼동할 위험이 있다.
