# T01 Hybrid A/B/C Human Review Guide

상태: `not_released`

4개 표본의 clean A/B/C가 준비되어야 blind reviewer 자료와 private mapping을 배포한다. 이번 실행은 익산시 clean triple gate에서 중단되었으므로 4-triple blind 자료를 생성하지 않았다.

향후 gate 통과 후 평가자에게는 mode, variant, modifier, native/neutral gate 수, selector 점수, mapping을 제공하지 않는다. 각 지역마다 무작위 X/Y/Z 순서의 세 글과 후보명·실제 소재지·주변 후보 여부·review source 검증에 필요한 최소 사실만 제공한다.

평가 항목은 검색 의도, 지역 관계, 후보 비교, 사실 활용, 문장 자연스러움, 섹션 흐름, 결측값 처리, review 신뢰감·출처, FAQ 추가 정보 가치, checklist 실행 가능성, 중복 억제, 가독성, 결정 지원, 광고성 억제, 템플릿 느낌, 전체 유용성, 최소 수정 후 게시 가능성이다.
