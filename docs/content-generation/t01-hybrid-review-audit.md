대상: `t01-hybrid-abc-clean-20260720-1710`, 익산시 Hybrid 1건.

## 결과

| 항목 | 결과 |
| --- | --- |
| eligible review 후보 | 선택된 원천 review 1건 |
| 본문 review 수 | 1 |
| 연결 학원 | 가나안자동차운전학원 (ID 120) |
| 출처 | `DrivingPlus 수강생 리뷰` |
| 출처 URL | 없음 — 서비스 label만 사용 |
| 작성자/작성일/평점/닉네임/내부 ID | 미출력 |
| 원천과의 충실도 | 원문 인용 일치 |
| 일반화 | 합격률 또는 전체 수강생 평가로 일반화하지 않음 |

Hybrid review gate는 review source, 개수, 연결 대상, metadata 노출에 대한 hard failure를 반환하지 않았다. 이번 실행은 Phase 1에서 중단되었으므로 review 사용/미사용 분포에 대한 4개 표본 통계는 산출하지 않았다.
