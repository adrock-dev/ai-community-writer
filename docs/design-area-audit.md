## 결론

- **완전히 죽은 영역은 없다.** "글유형별 디자인 편집"만 아래 편집기로 빠졌고, 이 카드는 이제 **"도메인 전체 디자인 설정(프리셋/전체강제/커스텀 메모) + 참고 설명 + 미리보기"** 역할.
- **중복 = ④ 글유형별 화면 구상 표**(아래 편집기와 겹침) → 제거 1순위.
- **정보성(접이식화 대상) = ①상태, ②디자인 종류 설명.**
- **기능(고급으로 정리) = ③프리셋 업로드/삭제, ⑥전체 강제, ⑤커스텀 메모.**

## P5 §3 슬림화 권장안 (이 카드)

1. **④ 중복 요약표 제거**(아래 편집기가 담당).
2. **② 디자인 종류 설명 → 접이식 도움말**.
3. **③ 프리셋 업로드/삭제 + ⑥ 전체 강제 → "고급" 접이식** 아래로.
4. **⑤ 커스텀 메모**: 이상적으론 "custom" 디자인을 고른 글유형 편집기 근처로 옮기는 게 자연스럽지만, 도메인 단일 필드라 현재 위치 유지도 무방(4b6cad1 힌트로 연결됨).
5. **① 미리보기 + 핵심 메시지**("글유형마다 어울리는 디자인 자동 적용, 대부분 그대로 두면 됨")만 앞에.

## 함께 고칠 stale 카피 (PR3 이후 안 맞는 문구)

- **line 707 헤더**: *"아래 표에서 특정 글 유형만 바꿀 수 있고"* — 이제 표는 읽기전용, 편집은 아래 편집기. 문구 수정 필요.
- **line 757 메모 힌트**: *"글 유형별 화면 구상에서 '커스텀'을 선택한 글"* — 이제 그 선택은 아래 편집기의 디자인 select 에서 함. 문구 수정.
- **line 395 튜토리얼 스텝**(`template-design`): "발행 화면 구상 저장" — 편집 위치 변경 반영 필요.
