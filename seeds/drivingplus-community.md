# 운전면허PLUS 커뮤니티 시드 키워드

`## 섹션 코드` 아래에 적는다. 띄어쓰기는 API 요청 시 자동으로 제거된다.

- `### 시드`: 네이버 연관 키워드를 받을 시작 키워드
- `### 포함어`: 이 섹션 주제로 남길 키워드가 하나 이상 가져야 하는 단어
- `### 제외어`: 이 섹션에서 뺄 단어 (같은 채널의 다른 섹션과 겹치지 않게)

운전면허PLUS는 드라이빙존 채널과 별개로 판단한다. 연수·장롱면허처럼 드라이빙존과 겹치는 주제도
운전학원 관점으로 다루며, 글 양식은 프롬프트(채널 × 글 유형)로 구분한다.
